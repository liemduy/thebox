# Idea Box / Liem's Planner

Static HTML app with Supabase Auth + sync.

## This build
- Box-level notes open in popup modal.
- Compact iPhone Notes-style formatting toolbar with text-size cycle, bold, italic, underline, strike, lists, indent/outdent.
- Mobile viewport/safe-area fixes.
- iPhone Add to Home support via manifest, apple touch icon, and standalone meta tags.

## Deploy
Upload all files in this folder to your existing GitHub Pages repo.
No SQL change is required for this build.
